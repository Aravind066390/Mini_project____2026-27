Pointer hierarchy

Overall structure
Level	Datatype	Represents
1	sqlr	Complete SQL result
2	sql_data * A	Internal data belonging to result
3	char ** value	Raw SQL rows
4	char *	Individual SQL row
3	float ** flt2	Extracted numeric data
4	float *	One numeric column
5	float	Individual numeric value

So the key idea is:

sqlr = SQL result object → sql_data = its data → char ** = raw rows → float ** = extracted numeric columns.
